# Layout Architecture

- Outer card: full width of the existing `max-w-7xl` page container.
- Header: compact editorial intro with live VLT badge.
- Controls: 3 equal columns on mobile, 6 equal columns from the small breakpoint upward.
- Vehicle stage: intrinsic 1774:887 media ratio; base image and SVG overlay occupy the same absolute coordinate system.
- Details: one column on mobile and a 1.2fr/0.8fr split on large screens.
- Metrics: 2 columns on small screens and 4 columns on large screens.
- No fixed widths and no horizontal overflow at 390 px.
